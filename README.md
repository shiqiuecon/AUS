# AUS course materials

Course presentations by Shi Qiu.

ECO351 narrated lessons are at [ECO351/](https://shiqiuecon.github.io/AUS/ECO351/): 26 classroom lectures and four supplementary decks, preserving the classroom graphs, equations, and raw Stata output. The course index links each self-contained HTML lesson. Transcripts, speed controls, automatic advancement, and offline downloads are included. Unreleased Quiz 3 and Quiz 4 recap pages are withheld; assessments and instructor files are not published.

The QBA201 index links all 13 lecture decks covering Lectures 1–25. Each lecture folder holds a self-contained presentation with its narration, equations, and charts embedded. Combined lecture numbers follow the classroom decks. Add future narrated lectures in separate folders under `QBA201/` and add their links to the course index.

Click **Start narrated lesson** once to enable audio. Each slide has a separate recorded explanation. Playback advances after the narration and stops at the end. Pause, change speed, jump to a slide, or read its transcript at any time. The QBA201 recordings use a locally generated synthetic voice with expanded business explanations. The side script follows each spoken paragraph; select a paragraph to replay it. Playing the lessons does not call an audio-generation API.

The lesson pages preserve the refined classroom slides as vector graphics with LaTeX equations. On small screens, use **Zoom** and pan to enlarge slide content. Lectures 18–19 additionally include interactive confidence-interval illustrations. Each HTML file can also be downloaded and opened offline.

This repository and its GitHub Pages website are public. Anyone can view or copy the published materials.

GitHub Pages publishes **main → /(root)**. The root page links to the QBA201 and ECO351 course indexes, which link to their available lectures. `.nojekyll` preserves folder names containing underscores.

All HTML pages request `noindex, nofollow`. This does not restrict access. The lesson requires one click on **Start narrated lesson** to enable sound, then advances automatically and stops at the end.

Only narrated teaching materials belong here. Assessment papers, answer keys, and the surrounding course authoring folders are not part of this repository.
