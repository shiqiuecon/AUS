# AUS course materials

Course presentations by Shi Qiu.

```text
AUS/
├── index.html
├── .nojekyll
└── QBA201/
    ├── index.html
    └── lecture_18_19/
        └── index.html
```

Each lecture folder holds a self-contained presentation with its narration, equations, and charts embedded. Add future narrated lectures in separate folders under `QBA201/` and add their links to the course index.

The repository is private. GitHub Pages eligibility for private repositories depends on the account's plan. An ordinary GitHub Pages website is public even when the repository is private; private repository visibility does not provide student access control.

To publish when the account is eligible, use **Settings → Pages → Deploy from a branch → main → /(root)**. The root page links to the QBA201 course index, which links to each available lecture. `.nojekyll` preserves folder names containing underscores.

All HTML pages request `noindex, nofollow`. This does not restrict access. The lesson requires one click on **Start narrated lesson** to enable sound, then advances automatically and stops at the end.

Only narrated teaching materials belong here. Assessment papers, answer keys, and the surrounding course authoring folders are not part of this repository.
