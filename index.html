Student support

Study with NotebookLM

Ask questions about the lecture materials in your own NotebookLM notebook. Start with the topic you are studying, then add more sources as you need them.

Use the direct material links below. Adding this homepage or a course index gives NotebookLM an overview only. It does not automatically follow the links to import all lectures.

  1. Create a notebook. Open NotebookLM, sign in, and create a notebook for your course.
  2. Copy the source link. Expand your course below. Right-click a Transcript or Slides PDF link and choose Copy link address (on a phone, press and hold the link). For ECO603, add both the transcript and PDF for fuller explanations.
  3. Add it to NotebookLM. Choose Add sources → Websites, paste the direct URL, and insert it. You can paste several URLs, one per line. Wait for each source to finish importing. If a PDF URL does not import, download that PDF and upload the file instead.
  4. Check, then ask. Open a source in NotebookLM and check that it contains the lecture content, not just a list of links. Ask a specific question and use the citations to check the answer against the source.
Try asking: “Using these sources, explain this topic step by step, show a worked example, and cite the relevant lecture. Then give me one practice question and wait for my attempt.”
